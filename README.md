# Harvard CS50’s Introduction to Computer Science (CS50x)

Este repositorio contiene descripciones de los “problem sets” y el proyecto final realizados durante el curso **CS50’s Introduction to Computer Science** de Harvard University.  
El curso explora los fundamentos de la informática y la programación, abarcando desde conceptos básicos hasta desarrollo web. 

---

##  Módulos y Problem Sets del curso

### **Semana 0 – Scratch**  
Introducción al pensamiento computacional y programación visual mediante Scratch.  
Objetivo: Crear un programa interactivo (juego o animación) que muestre lógica, bucles, condiciones y eventos.

---

### **Semana 1 – C**  
Lenguaje de programación C: variables, condicionales, bucles, funciones, entrada/salida básica.  
Problem Sets típicos: “Hello, world”, pirámides de bloques (Mario), validación de números de tarjetas de crédito.

---

### **Semana 2 – Arrays y Cadenas – C**  
Conceptos de arrays, strings, argumentos de línea de comandos en C.  
Problem Sets: Manejo de cadenas, arrays de datos, cifrados simples.

---

### **Semana 3 – Algoritmos – C**  
Algoritmos de búsqueda (lineal, binaria), ordenación (bubble, selection, insertion, etc.), análisis de eficiencia.  
Objetivo: Comprender cómo pensar algorítmicamente y elegir estructuras/personas adecuadas.

---

### **Semana 4 – Memoria – C**  
Conceptos de punteros, memoria dinámica, asignación, desasignación, memoria estática vs dinámica, fugas de memoria.  
Problem Sets: Manejo de memoria al reservar matrices, liberar memoria, estructuras enlazadas, etc.

---

### **Semana 5 – Estructuras de Datos – C**  
Listas enlazadas, tablas hash, árboles binarios, tries, grafos básicos.  
Objetivo: Usar estructuras que permitan almacenar y acceder a datos eficientemente.

---

### **Semana 6 – Python**  
Introducción al lenguaje Python para la programación rápida y scripting.  
Problem Sets: Reescribir o expandir tareas previas en Python, procesamiento de datos, lectura de ficheros.

---

### **Semana 7 – SQL y Bases de Datos**  
Bases de datos relacionales, lenguaje SQL, consultas, relaciones entre tablas, integridad de datos.  
Problem Sets: Construir consultas, diseñar esquema de base de datos, implementar una pequeña base de datos para un propósito.

---

### **Semana 8 – HTML, CSS, JavaScript**  
Desarrollo web front-end: lenguajes y tecnologías de web, manipulación DOM, eventos, estilos, diseño responsivo.  
Problem Sets: Crear páginas web interactivas, combinar front-end con lógica, integrar con bases de datos o servidores simples.

---

### **Semana 9 – Flask (Desarrollo Web con Python)**  
Framework Flask para backend con Python, integración con SQL, rutas, sesiones, autenticación.  
Problem Sets: Crear una aplicación web completa (login, registro, base de datos, operaciones CRUD).

---

### **Semana 10 – Proyecto Final / Extensión**  
Aplicación web para aprender alemán mediante flashcards, desarrollada con Flask, HTML, CSS y SQL. Permite al usuario añadir, estudiar, editar y eliminar vocabulario organizado por categorías.

---

##  Tecnologías y lenguajes utilizados  
- C  
- Python  
- SQL  
- HTML / CSS / JavaScript  
- Framework Flask  
- Scratch (programación visual)  
- Estructuras de datos, algoritmos, pensamiento computacional

---

##  Temas principales aprendidos  
- Pensamiento algorítmico y resolución de problemas  
- Abstracción, encapsulación y eficiencia de código  
- Estructuras de datos (arrays, listas, árboles, hash tables)  
- Lenguajes de programación de bajo nivel y de alto nivel  
- Bases de datos relacionales y consultas SQL  
- Desarrollo de aplicaciones web full-stack  
- Gestión de memoria, seguridad básica, lógica de programación
