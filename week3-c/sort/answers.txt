sort1 uses: Bubble sort

How do you know?: Because when sorting the same random txt file as the other 2 algorithms, this proved to be the slowest one in completing the sorting,
which is a charateristic of the bubble sorting. Also, It proved to be kind of slow, even when evaluating an already sorted file.

sort2 uses: Merge sort

How do you know?: Mainly because this was the fastest algorithm in sorting a random file, which is typical in merge.
Also it was slower than others when evaluating an already sorted file, since the process of dividing is slower than just a pass like the other algorithms.

sort3 uses: Selection sort

How do you know?: This was the fastest algorithm when evaluating a sorted file, which makes sense because since it is already sorted,
it will only have to look once at each number , which is faster than dividing into groups, or compare pairs.
